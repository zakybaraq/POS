<task type="auto">
  <name>Task 3: Create reorder API routes</name>
  <files>src/routes/reorder.ts</files>
  <action>
Create src/routes/reorder.ts:

```typescript
import { Elysia } from 'elysia';
import * as reorderService from '../services/reorder';

export const reorderRoutes = new Elysia({ prefix: '/api/reorder' })
  .get('/suggestions', async () => {
    return reorderService.getReorderSuggestions();
  })
  .get('/suggestions/:id', async ({ params }) => {
    const suggestion = await reorderService.getSuggestionById(Number(params.id));
    return suggestion || { error: 'Not found' };
  })
  .post('/generate-po', async ({ body }) => {
    const { suggestionId, createdBy } = body as any;
    if (!suggestionId || !createdBy) return { error: 'suggestionId and createdBy required' };
    return reorderService.generateDraftPO(suggestionId, createdBy);
  });
```

Add routes to index.ts after creation.
